BASE URL: http://localhost:5010

INSTRUCCIONES GENERALES:
- Sustituye <TOKEN> por el token JWT obtenido en el paso de login.
- Sustituye los placeholders <driverId>, <vehicleId>, <vehiclePlaca>, <routeId>, <planId> según las respuestas que devuelva el gateway.
- Puedes usar curl o PowerShell Invoke-RestMethod. En Windows PowerShell las comillas JSON se pasan tal cual.

1) LOGIN (obtener token)
POST /api/auth/login
Headers: Content-Type: application/json
Body:
{
  "Username": "admin",
  "Password": "admin123"
}

Ejemplo curl:
curl -s -X POST "http://localhost:5010/api/auth/login" -H "Content-Type: application/json" -d "{\"Username\":\"admin\",\"Password\":\"admin123\"}"

Ejemplo PowerShell:
Invoke-RestMethod -Method Post -Uri "http://localhost:5010/api/auth/login" -Body '{"Username":"admin","Password":"admin123"}' -ContentType 'application/json'

---
2) LIST USERS
GET /api/auth/users
Headers: Authorization: Bearer <TOKEN>

curl:
curl -s -H "Authorization: Bearer <TOKEN>" "http://localhost:5010/api/auth/users"

PowerShell:
Invoke-RestMethod -Method Get -Uri "http://localhost:5010/api/auth/users" -Headers @{ Authorization = "Bearer <TOKEN>" }

---
3) CREATE DRIVER
POST /api/drivers
Headers: Authorization: Bearer <TOKEN>, Content-Type: application/json
Body (ejemplo):
{
  "FirstName": "Test",
  "LastName": "Driver",
  "DocumentNumber": "99999999",
  "PhoneNumber": "+1000000000",
  "Email": "test.driver@x.com",
  "LicenseNumber": "LIC999",
  "LicenseCategory": 2,
  "LicenseExpiryDate": "2028-11-05T00:00:00",
  "DriverType": 1,
  "HireDate": "2025-11-05T00:00:00"
}

Respuesta esperada contiene: driver.id (guardar como <driverId>)

curl:
curl -s -X POST "http://localhost:5010/api/drivers" -H "Authorization: Bearer <TOKEN>" -H "Content-Type: application/json" -d @- <<'JSON'
{ "FirstName":"Test","LastName":"Driver","DocumentNumber":"99999999","PhoneNumber":"+1000000000","Email":"test.driver@x.com","LicenseNumber":"LIC999","LicenseCategory":2,"LicenseExpiryDate":"2028-11-05T00:00:00","DriverType":1,"HireDate":"2025-11-05T00:00:00" }
JSON

PowerShell:
Invoke-RestMethod -Method Post -Uri "http://localhost:5010/api/drivers" -Headers @{ Authorization = "Bearer <TOKEN>" } -Body '{"FirstName":"Test","LastName":"Driver","DocumentNumber":"99999999","PhoneNumber":"+1000000000","Email":"test.driver@x.com","LicenseNumber":"LIC999","LicenseCategory":2,"LicenseExpiryDate":"2028-11-05T00:00:00","DriverType":1,"HireDate":"2025-11-05T00:00:00"}' -ContentType 'application/json'

Notas finales:
- Algunos endpoints pueden devolver objetos anidados; adapta la extracción de IDs según la respuesta real (p.ej. response.driver.id o response.id).
- Si tienes rutas protegidas adicionalmente, asegúrate de pasar el header Authorization.
- Si prefieres, puedo ejecutar estas llamadas una por una desde aquí y devolverte las respuestas; confirma y continuaré.
