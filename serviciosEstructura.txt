3.1 AuthService
Responsabilidades: autenticación (login), emisión y renovación de JWT, gestión de usuarios y roles (Admin / Operador / Supervisor), revocación de tokens (lista negra si necesario), endpoints para validar/refresh token.
Almacenamiento: SQL Server (usuarios, roles, refresh tokens).
Integraciones: actúa como autoridad de identidad; los demás microservicios validan JWT (interceptors gRPC) o delegan validación al Gateway.
Notas: generar claves (RSA) para firma; rotación de claves planeada.
3.2 DriversService
Responsabilidades: CRUD de choferes; disponibilidad; asignaciones (vehículo/ruta); historial de asignaciones; verificación por tipo de maquinaria (solo choferes certificados para pesado).
Modelos: Driver { id, nombre, licenciaTipo, certificadoPesado?, estado, contacto, metadata }
BD: SQL Server (relacional).
3.3 VehiclesService
Responsabilidades: CRUD de vehículos; tipado (Liviana/Pesada), estado operativo, asociación con choferes, mantenimiento programado, telemetría básica (marca, modelo, año, placa, chasis).
Modelos: 
VehicleType {
  id,
  tipoMaquinaria,     // Liviana / Pesada
  subtipo,            // Camioneta 4x2, Camión mediano, Excavadora, etc
  tipoMotor,          // Gasolina / Diesel / Híbrido
  consumoBase,        // L/100km
  factorMotor,        // 0.85, 1.0, 0.7, etc.
  pavimentado,        // 1.0
  montañoso,          // 1.3
  mixto,              // 1.15
}

Vehicle {
  id,
  placa,
  chasis,
  marca,
  modelo,
  año,
  vehicleTypeId,      // FK → VehicleType
  estado,
  km,
  lastMaintenance
}
BD: postgres;
3.4 RoutesService
Responsabilidades: CRUD de rutas; definición de puntos (origen/destino), distancia, condiciones (pavimento, montaña), estimación de consumo por tipo de vehículo, asignación a viajes.
Modelos: Route { id, nombre, origen, destino, distanciaKm, tipoTerreno, createAt }
BD: postgres.
3.5 FuelService
Responsabilidades: registrar consumos reales por viaje/ruta/vehículo/chofer; comparar consumo estimado vs real; generar reportes agregados por vehículo, chofer, ruta, tipo de maquinaria; detectar outliers (consumos inusuales).
Modelos: FuelPlan {
  id: number,
  vehicleId: number,
  driverId?: number,           // opcional si aún no se asigna
  routeId: number,
  datePlanned: date,
  distanceKm: number,
  tipoTerreno: enum('pavimentado','montañoso','mixto'),
  consumoBase: number,         // L/100km desde VehicleType
  factorMotor: number,         
  factorTerreno: number,
  estimatedLiters: number,     // calculado para planificar combustible
  tipoMaquinaria: string,
  estado: enum('planificado', 'en progreso', 'completado')
}
BD: postgres para registros; 
Integraciones: consulta a VehiclesService y DriversService por gRPC para validar IDs y consultar meta info.

Cada microservicio tiene una responsabilidad clara:
RoutesService->Conocer rutas: origen, destino, distancia, condiciones del camino. Se puede integrar OpenStreetMap + OSRM API (gratuito y bastante exacto).
VehiclesService->Conocer vehículos: tipo (liviano/pesado), consumo base, motor, mantenimiento.
FuelService->Conocer consumos de combustible reales y estimados; generar reportes y alertas.
Por lo tanto:
RoutesService solo provee la distancia y factores (pavimento, dificultad). 
VehiclesService provee el consumo base (por km o por tipo).
FuelService combina ambos datos para estimar el uso esperado de combustible.

Flujo de integración resumido
[VehiclesService] ---> tipoVehiculo
[RoutesService] -----> distanciaKm, dificultadRuta
       ↓
     (gRPC/REST)
       ↓
[FuelService]
    - Calcula consumo estimado
    - Registra FuelRecord (con consumo real + estimado)
    - Reporta outliers


Servicios
AuthService->Control de usuarios, JWT, roles->SQL Server->Validación JWT/gRPC interceptors
DriversService->Choferes, certificaciones, disponibilidad->SQL Server->Consultado por FuelService
VehiclesService->Vehículos, tipo, consumo base, mantenimiento->PostgreSQL->Consultado por FuelService
RoutesService->Rutas, distancia, dificultad, estimación base->PostgreSQL->Consultado por FuelService
FuelService->Consumo real y estimado, reportes->PostgreSQL->Integra datos de Vehicles y Routes
