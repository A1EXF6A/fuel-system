Ejemplo para POST http://localhost:5010/api/auth/validate

Descripción:
Endpoint para validar un token JWT y obtener si es válido y el rol asociado.

URL:
http://localhost:5010/api/auth/validate

Método:
POST

Headers:
Content-Type: application/json

Body (ejemplo):
{
  "Token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJVc2VybmFtZSI6ImFkbWluIiwicm9sZSI6IkFkbWluIiwiZXhwIjoxNjk0NjQ4MDB9.signedpart"
}

Respuesta esperada (ejemplo):
{
  "valid": true,
  "role": "Admin"
}

Notas:
- El campo del body se llama "Token" (mayúscula inicial) porque el DTO en el gateway es `ValidateTokenRequestDto(string Token)`.
- Si necesitas validar el header Authorization (Bearer ...), el gateway tiene endpoints que lo reenvían a los servicios; este endpoint valida el token de forma explícita desde el cuerpo.
- Si quieres, puedo ejecutar esta llamada contra tu gateway y pegar la respuesta (necesito un token válido o puedo usar la cuenta admin para obtener uno primero con /api/auth/login).
